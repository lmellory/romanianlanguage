# Vorbește

**Румынский понемногу каждый день.**

Бесплатный браузерный тренажёр: спряжение глаголов, сборка предложений, перевод, чтение с подсказками и личный словарь с интервальным повторением.

[**Открыть приложение →**](https://lmellory.github.io/romanianlanguage/)

Без регистрации, сервера и платных API. Прогресс остаётся в вашем браузере.

## Что можно делать

| Раздел | Возможности |
| --- | --- |
| Практика | Спряжение в четырёх временах/наклонениях, предложения из слов, перевод с подсказками по диакритике. Сложность меняется в настройках. |
| Словарь | Свои слова, добавление из текстов, поиск, удаление, повторение по SM-2. Забытое слово возвращается через минуту. |
| Чтение | Короткие тексты с переводом знакомых слов по нажатию и озвучкой устройства. |
| Язык и культура | Произношение присяги, разговорные вопросы и справочные материалы о Румынии. |
| Ежедневная практика | Опыт, серия дней, задания на день и таймер фокуса от 1 до 180 минут. |
| Настройки | Светлая и тёмная темы, экспорт и проверяемый импорт JSON, установка на главный экран. |

Интерфейс адаптирован к телефону и компьютеру. Поддерживаются клавиатура, Escape, управление фокусом в диалогах и уменьшение анимации.

## Начать заниматься

1. Откройте приложение по ссылке выше.
2. Выберите A1 или пройдите ориентировочный тест из 20 вопросов.
3. Выполните упражнение или добавьте несколько своих слов.
4. Вернитесь в словарь, когда карточки будут готовы к повторению.

Тест выбирает сложность внутри приложения. Он не является оценкой CEFR, экзаменом или подтверждением уровня. Метки A1–C2 — ориентиры для подборки материала, а не полноценная учебная программа.

## Офлайн и установка

Откройте приложение через HTTPS и дождитесь первой загрузки. Service worker сохраняет основные файлы приложения. После этого интерфейс, упражнения и словарь доступны без сети. В меню поддерживаемого браузера можно выбрать «Установить» или «На экран Домой».

Озвучка зависит от голосов, установленных на устройстве. Наличие румынского голоса и работа синтеза речи без сети зависят от браузера и ОС. Установка приложения также зависит от поддержки браузера.

## Прогресс и резервные копии

- Данные сохраняются в `localStorage` текущего браузера. Синхронизации между устройствами нет.
- Настройки → **Экспорт** скачивает JSON с прогрессом и словарём.
- Импорт проверяет типы, даты и карточки до замены данных и требует подтверждения.
- Старый ключ `vorbeste_ro_state_v1` сохранён: при обновлении на том же домене слова и накопленный опыт остаются.
- Старая ссылка `vorbeste-pro.html` перенаправляет на главную страницу.
- Если сохранение повреждено, приложение пытается оставить исходную копию под ключом `vorbeste_ro_state_v1_recovery`.
- Очистка данных сайта удаляет локальный прогресс. Перед ней сделайте экспорт.
- Таймер работает при открытой вкладке, учитывает задержки в фоне и сбрасывается при перезагрузке.

## Запуск для разработки

Нужен Node.js 22 или новее. Зависимостей нет.

```sh
npm start
```

Откройте `http://127.0.0.1:4173/`. Открытие HTML двойным щелчком не поддерживает полноценную установку и офлайн-кэш; используйте локальный сервер.

```sh
npm run check
npm test
```

Проверки охватывают перенос старого прогресса, повреждённый импорт, расчёт интервалов повторения, локальные даты, повторные нажатия, пустые ответы, таймер после задержки и безопасное отображение собственных слов.

## Структура

- `index.html` — оболочка и доступная навигация.
- `styles.css`, `theme.css` — базовые стили и светлая/тёмная темы.
- `data.js` — учебные материалы и словарь.
- `core.js` — проверка прогресса, календарные даты и алгоритм повторения.
- `app.js` — упражнения, словарь, чтение и интерфейс.
- `sw.js`, `manifest.webmanifest` — офлайн-режим и установка.
- `test/` — регрессионные тесты без сторонних библиотек.

При изменении файлов, перечисленных в `sw.js`, повышайте версию кэша. Открытая старая вкладка может удерживать прежнюю версию до закрытия; это предотвращает смешивание файлов разных версий во время занятия.

## Источники и границы

Учебные примеры и переводы находятся в `data.js`. Подсказки при чтении используют локальный словарь, поэтому не каждая словоформа имеет перевод. Раздел культуры предназначен для языковой практики и не заменяет официальные требования или юридическую консультацию.

Текст присяги сверяется с [законом Румынии № 21/1991, статья 20](https://legislatie.just.ro/Public/DetaliiDocument/121439). Требования к гражданству проверяйте по официальным источникам.
